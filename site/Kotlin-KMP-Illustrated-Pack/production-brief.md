# Production brief

Audience: software engineer learning Kotlin/KMP. Depth: fundamentals + best practices. Outcome: an offline illustrated reference that explains mechanisms and decisions, with Android and iOS boundaries visible.

Design source: deep_learning_architectures_cheatsheet_2026_v1. All required design inputs were consulted. Use off-white paper, indigo title ink, yellow highlighting, purple double underline, numbered circular badges, pastel cards, small semantic sketches, and restrained notebook binding. Exact editable SVG labels take priority over art.

Scope: 12 topics, four learning stages, 14 semantic figures plus an overview; no exhaustive stack ranking. Current Swift export is Alpha. Code sketches are not compiled. Performance improvements are hypotheses to measure.
