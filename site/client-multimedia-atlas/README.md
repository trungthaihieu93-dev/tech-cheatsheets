# Client Multimedia Libraries — Illustrated Atlas

Open `index.html` in a browser after unzipping. It contains the entire atlas and embedded diagrams; no server, CDN or installation is required to read it.

- Depth: Libs/frameworks/stacks (level 3, cumulative).
- 18 topic sheets; 20 editable SVG diagrams; 8 pictured libraries.
- 3 proposed worked architectures, plus a documented Video.js engineering example.
- Source ledger: 41 primary pages, reviewed 2026-10-10.
- `topics/`: individual offline sheets. `figures/`: reusable SVGs.
- `pack.json`: editable content/evidence. `sources.md`: direct research pointers.
- `examples/`: illustrative excerpts, intentionally not an executable application.
- `manifest.json`: packaged file sizes and SHA-256 checksums.

Examples were inspected against documentation but not compiled/run against a media backend. Pin project versions and test real browser/codec/DRM combinations before adoption. Vidstack status and Video.js/ReactPlayer migration boundaries are called out explicitly. Older Clappr component docs are used as architecture evidence and point to its current monorepo.

Diagrams can be swiped horizontally on small screens. Check questions expand to reveal their answers. Research links require a network; the lessons do not.
